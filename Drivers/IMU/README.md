# MPU6050 驱动与姿态估算

默认硬件为 **MPU6050 / GY-521**，兼容用户确认的 WHO_AM_I=0x70 替换模块。建议断电后把 AD0 接 GND，固定地址 `0x68`；AD0 接高时地址为 `0x69`。是否自带 AD0 下拉需要查看具体模块，不能仅凭未接 AD0 判断故障。驱动默认先读取 WHO_AM_I：首选 IMU_ADDRESS，NACK 或 ID 不符时读另一个地址，只有 ID 为 0x68 或 0x70 才执行复位/配置，仍拒绝未知 ID。IMU_AUTO_ADDRESS=0 可关闭地址兼容。总线使用共享 I2C1 PB8/PB9。

已阅读用户提供的 `E:\STM32project\6-2 硬件收发IIC\hardware\MPU6050.c` 和配套头文件。该参考驱动版权归江协科技所有。本模块保留其寄存器配置思路，改成异步总线、14 字节连续采样、错误状态和姿态估算；不使用参考工程的 I2C2 PB10/PB11 阻塞轮询。参考工程的量程与本工程不同，不能混用其换算比例。

初始化包括上电等待、WHO_AM_I 校验、软复位等待和配置，全部由 `IMU_Process(now_ms)` 推进。配置：PLL X 轴时钟；PWR_MGMT_2=0 开启六轴；采样分频 9、DLPF=3；陀螺仪 ±500 °/s（65.5 LSB/(°/s)）；加速度计 ±2g（16384 LSB/g）；每 10 ms 读取 `0x3B` 开始的 14 字节。WHO_AM_I 接受 `0x68` 或用户确认的 `0x70`，不要把这个 ID 与 I2C 地址混淆。兼容模块的寄存器行为和量程仍须实物核对；温度字段沿用 MPU6050 的公式，未作为控制或页面显示数据使用。

没有有效样本时，OLED 保留 GX/GY/GZ 和 °/s，数值显示 `--`，不是伪造零值。下方显示当前探测地址及最近失败原因：`WHO NACK`、`WHO TIMEOUT`、`WHO BUS ERROR`、`WHO ID=xx`、`RESET ...`、`CONFIG ...` 或 `READ ...`。失败原因在重试阶段保留，配置完成后清除。地址兼容不能解决供电、上拉、信号质量或器件故障。

启动后需要把机构放到作为 **零姿态** 的位置保持静止约 2 秒：200 次连续合格采样求陀螺仪零偏与安装角度偏移。明显旋转、加速度异常或重力角变化会清空该窗口，10 秒未完成显示 FAULT，仍采样供再次校准。`IMU_RequestCalibration()` 可以发起重新校准；重新校准时闭环不能继续输出。

未校准时 OLED 显示 CAL n/200 和静止提示，校准完成后显示 X/Y/Z 姿态角。HOLD 启用必须使用有效且已校准的样本；未完成时提示 CALIBRATE IMU FIRST，过期时提示 IMU SAMPLE STALE，通信故障显示实际原因。不能仅凭 GX/GY/GZ 有数值认定姿态已经校准。

```c
IMUSample sample;
if (IMU_GetSample(&sample) && sample.calibrated) {
    /* gyro_x/y/z_dps 单位 °/s；roll/pitch/yaw_deg 单位 °。 */
}
```

Roll/Pitch 用重力角 + 陀螺仪积分的互补滤波，时间常数 0.5 秒；加速度范数偏离 1g 较大时暂不把它作为重力参考。积分使用实际采样时间，间隔超过 100 ms 时重新获取重力角，不积分未知时间。读失败/全零加速度/超过 100 ms 未更新会标记样本无效；`IMU_IsReady()` 要求已校准且样本新鲜。初始化或读失败后间隔 1 秒重试。

**Yaw 是相对积分角，六轴 MPU6050 没有磁力计，不能提供长期无漂移的绝对航向。** Euler 表示在 Pitch 接近 ±90° 时有奇异性，本工程用于约 ±60° 的舵机倾角演示；不适合任意三维翻滚或精确惯性导航。Roll/Pitch 采用“X 前、Y 左/右按实际安装、Z 上”的右手传感器轴定义，舵机安装方向需要上板确认，可在控制模块选择轴与输出方向。

`IMU_SetPaused(true)` 停止提交新采样，不取消在途总线传输；普通 Sleep 保持 IMU 调度启用。OLED 熄屏不会停止 IMU。

主机测试已覆盖校准、运动拒绝、符号与量程转换、Roll/Pitch 融合、Yaw 积分、时间回绕、共享总线、故障重试与过期检测。实物的噪声、轴向、供电和振动影响必须上板测定。

寄存器与量程依据：[TDK InvenSense MPU-6000/MPU-6050 Register Map](https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Register-Map1.pdf)。
