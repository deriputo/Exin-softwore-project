# Kp1.0、Ki0静止对照

版本`v0.6.3-kp10-ki0-diagnostic`。用户反馈关闭积分仍静止左右摆动，说明摆动不依赖积分持续累积，不能据此确定P/D或传感器噪声谁是根因。用户明确选择把Kp改1.0。

本版仅APP_HOLD_NORMAL_KP从1.6改1.0，Ki=0、Kd=0.02、死区0.5°、限速180°/s、方向及故障保护均保留。control/app_integration主机检查通过，包括实际应用持续偏差下的比例输出及无积分漂移检查。没有由助手编译或烧录MCU，尚未实物验收。

用户Keil Rebuild并下载后，底座水平放稳等待校准；开启HOLD、目标约90°，手离开机构静置20秒，不做倾斜扰动。反馈摆动消失、减轻还是不变；若持续摆动就关闭HOLD。可记录静止TRACE到trace_kp10_ki0.csv供比较，I应为0。

此版仅用于定位静止摆动，不要求消除持续倾角稳态误差，也不作为完整定角性能版。下一步需要根据实物结果，避免一次改动P、D和滤波等多个因素。
