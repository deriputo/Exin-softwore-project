# 提高Kp与非线性变速积分试验

标签`v0.6.0-nonlinear-pi-test`，继承v0.5.0-ki050-test。用户选择保留连杆IMU闭环，明确提出提高Kp并使用非线性变速积分，函数由助手决定。

本页为历史试验：用户已反馈静止左右抽动，未通过验收。当前工作区转为v0.6.1，将Ki峰值降到0.8，详见NONLINEAR_I08_TEST.md。下文数值对应历史2.0参数，原曲线须从v0.6.0标签查看，工作区同名曲线随当前参数更新。

## 算法与曲线

仍为位置式PID：输出=bias + direction*(P+I+D)。Kp从0.8改1.6，积分最大Ki从0.50改2.0，并引入误差尺度8°：

```text
e = 目标姿态 - 实测姿态
若 |e| <= 0.5°，用于P和积分的e置0
Ki_eff = 2 / (1 + (e / 8)^2)
候选I = 原I + Ki_eff * e * dt
```

这不是只加大Kp。此前单独Kp1.6、Ki0.5的简化模型达标6900ms，比旧Kp0.8/Ki0.5的6420ms稍慢；该候选没有烧录，也没有单独保存成固件版本。

有效Ki随误差绝对值增大而平滑降低，用于减弱大误差时的积分。积分增量还要乘e和dt，因此接近目标时实际增量会随误差减小而变小，不会因Ki_eff增大而无限加速。增量幅值在|e|=8°达到最大（正常20ms时0.16°/周期），误差更大时再降低；小误差区比原Ki0.5更积极地消除残差。

|误差绝对值|有效Ki|候选积分增量绝对值/20ms|
|---|---|---|
|0～0.5°|公式极限约2，但积分门控关闭|0|
|1°|1.969|0.0394°|
|5°|1.438|0.1438°|
|8°|1.000|0.1600°|
|16°|0.400|0.1280°|
|30°|0.133|0.0797°|

## 保留与测试

Kd0.02、方向-1、20ms控制周期、0.5°死区、180°/s限速、输出范围、抗积分饱和、故障锁存、OLED、协议均保持。ControlConfig新增integral_error_scale_deg，默认0代表旧恒定积分，兼容原核心用法；应用设置8。未改IMU姿态解算，IMU_INVALID仍是已知未解决问题。

control与app_integration主机测试通过。包括积分函数正负误差数值、死区不累积、60秒小噪声、无效样本锁存、目标0～180°和既有限幅/限速检查。简化8°阶跃模型（含进入±1°后的1秒保持确认）旧版6420ms，新版2600ms，仅说明模型改善，不代表SG90实物速度或无振荡保证。

## 用户验收

1. 用户自行Keil Rebuild/烧录。底座水平、IMU随连杆固定，等静止校准完成。
2. 开HOLD，确认约90°目标及FAULT=OFF，先静置10秒，看是否新增抽动或摆动。
3. TRACE记录另存trace_nonlinear.csv。水平静置2秒，用固定小支撑倾斜约5°，放好并松手后不再碰底座，记录至少30秒，不在末尾放回水平。
4. 反馈松手后是否仍一卡一卡、纠偏是否更快、有无明显过冲/持续摆动，以及CSV。先验收小角度，不直接进行大角度限位测试。模型不能代替这项实物验收。
5. 若出现持续摆动或明显恶化，关闭HOLD；如果IMU_INVALID，保留首次故障记录再查询，不能把故障停机当作稳定。
