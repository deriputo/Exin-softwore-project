# 纯比例静止对照

版本`v0.6.4-p-only-diagnostic`。用户反馈Kp1.0/Ki0/Kd0.02仍静止左右摆动，已同意关闭D作单项对照。不能提前确定P、D或硬件为唯一根因。

本版唯一固件参数改动：Kd0.02→0；Kp1.0、Ki0、死区0.5°、180°/s限速、方向和保护均保留。位置式纯P输出仍以HOLD开启时捕获的输出为基准，积分/微分状态可能计算或保留相关中间量，但I、D控制贡献为0。

control及app_integration主机测试通过：既有限幅/限速/故障检查，应用正负1°样本跳变后40ms输出符合纯P且没有D尾随，持续偏差10秒无积分漂移。只说明软件配置生效，不代替实物稳定性验收。助手未执行MCU编译烧录。

## 用户测试

1. 用户Keil Rebuild并下载，底座水平、IMU随连杆固定，等待校准。开HOLD并确认目标约90°，手离开机构，不施加倾斜。
2. 观察20秒，反馈摆动消失、减轻还是不变。若持续摆动，关闭HOLD。
3. 如可操作，录制15～20秒静止TRACE，另存trace_p_only.csv。I和D应始终0；对照measured、P及servo三列。CSV中的servo是程序舵机角度指令，不是实测舵机轴角。
4. 指令也来回变化时，继续检查控制/姿态噪声；指令基本不变但实物仍摆时，优先检查执行器、供电或机械因素。20Hz TRACE可能漏掉更快变化，不能仅凭曲线平直就证明PWM电气信号恒定。

本版不用于扰动恢复速度或消除稳态误差验收。不要根据本版残余偏差直接恢复积分。IMU_INVALID仍未修复。
