# 大误差不衰减到零的有界积分

版本`v0.7.0-bounded-i-test`。用户确认上位机记录正常，主要问题是底座停止后缓慢间歇向目标挪动，授权改进积分调度。保留Kp1.0、Kd0及位置式连杆IMU闭环。

## 改动

上一版Ki_eff=0.5/[1+(e/8)^2]在误差30°时仅0.033，积分贡献增长约1°/s，可能拖慢大误差补偿。SG90死区/机械摩擦对间歇动作的影响尚未单独测定，不能宣称积分是唯一原因。

新版采用有上下限、随误差幅值平滑增加的积分增益：

```text
Ki_eff = 0.4 + 0.6 * e^2 / (e^2 + 4^2)
候选ΔI = Ki_eff * e * dt
```

|误差绝对值|新版Ki_eff|候选积分增量绝对值/20ms|
|---|---|---|
|1°|0.435|0.00871°|
|4°|0.700|0.0560°|
|8°|0.880|0.1408°|
|20°|0.977|0.3908°|
|30°|0.990|0.5937°|

有效增益有下限0.4、上限1.0；但现有±0.5°死区内仍停止积分累积，已有补偿保留。候选增量仍须通过积分限幅和抗饱和检查，并非总舵机速度。大误差时较强，接近目标时减弱，近目标增益不比上一版峰值0.5更高。不能承诺彻底消除舵机机械死区引起的间歇动作。

## 保留与软件验证

Kp1、Kd0、0.5°死区、180°/s限速、20ms周期、方向-1、抗积分饱和、IMU有效性和故障锁存均不变。核心增加integral_min_ki参数，要求0<=min<=ki；误差尺度0时仍走通用恒定Ki。新调度替代旧调度，旧实现完整保存在Git。

control/app_integration主机测试通过：非线性增益上下界、正负误差、死区不累积、故障锁存，应用持续误差积分实际参与，目标/输出/限速回归。

同一一阶机构模型，Kp1、D0、±1°标准且保持1秒：

|底座阶跃|上一版|新版|
|---|---|---|
|±8°|7060ms|6280ms|
|±30°|18760ms|9180ms|

旧版在同一控制器中使用等效恒定瞬时Ki=0.5/[1+(e/8)^2]复现，避免更换模型引起假改善。仿真每轮持续60秒，后续若再次离开误差带则重新计算达标时刻；同时约束越过目标另一侧的过冲不超过1°。结果不是SG90实测，不代表更快/复杂机构也稳定。最初最低Ki0.25候选使8°模型变慢，未交付，最终选0.4。

## 用户测试

1. 用户Keil Rebuild/下载。底座水平、IMU固定连杆，等静止校准。助手未执行MCU编译或烧录。
2. 开HOLD、目标约90°，先静置20秒。若持续左右摆动，关闭HOLD并反馈，不做更大扰动。
3. 静止正常后，TRACE记录新文件trace_bounded_i.csv。先用固定支撑倾斜约5°，放好松手后不碰机构，记录30秒，不在末尾回正。
4. 小角度无明显摆动/过冲后，再另录约15～20°的固定倾角，不靠近机械限位；本轮不直接试80°极限。
5. 记录前后直接查询SERVO HOLD ?，不要重新开启HOLD再查询；一起提供两条回复和CSV，说明放置时段及实物有无间歇挪动、过冲或持续摆动。停止测试时可关闭HOLD，但需说明何时关闭。

IMU_INVALID仍是已知未解决问题；发生时保留首次故障记录，不用故障停机判断稳定性。Git标签v0.7.0-bounded-i-test及backups/v0.7.0-bounded-i-test.zip；前版v0.6.5保留，待本轮实物验收。
