# ±1000°/s持续运动无故障实测保存点

标签v0.16.1-gyro1000-motion-snapshot，固件源码与v0.16.0-gyro1000-test相同，仅归档本轮数据及用户反馈。不是新的控制参数版，也不代表全项目或全部性能验收。

用户提供stm32_trace.22csv.csv并反馈“没有出现错误”，随后说明最后才停止转动底座，未给出明确停止时间。本轮主要是持续运动试验，没有独立长静止段，不能计算停止后恢复时间、停止后过冲或静止抖动验收结果。

数据结果：

- 3525帧、70.48秒，板端相邻时间全部20ms；所有fault均NONE。
- 目标89.8°；实测16.9～152.2°，运动中绝对记录误差最大73.0°。该值不是停止后过冲，也不能因为用户主动大幅转动就忽略动态跟踪误差。
- 输出指令11.6～167.2°，未触及0/180°指令端点；431帧saturated=1，约12.227%。这431帧的指令相对前一帧均约改变3.6°，与180°/s×20ms一致，说明软件输出限速确实在频繁起作用。saturated并非实际轴位置反馈，不能把它称为机械堵转。
- 最后一次输出变化约67.98秒；最后2.5秒输出固定90.2°，实测89.3～89.7°，相对目标约0.2～0.5°偏差。因用户最后才停止，不能直接把这一段认定为底座固定的稳态段。

结论：本轮70秒持续运动未再触发此前GYRO_RANGE或GRAVITY_TIMEOUT，是本次数据支持的结果，不能保证任意运动都无故障。实际角速度的原始数据没有进入TRACE，本轮也不能反推最高真实角速度或证明不存在任何量程/供电问题。

当前参数、200ms接续、±1000°/s换算/读回及平滑死区均保留，未改代码。建议后续独立评估180→240°/s输出限速，提高指令跟随速度而不同时改PID；尚未修改或模型验证，需要先完成模型检查及单独实物验收，仍不能保证补偿任意快速转动。重点同时看停止后回摆和此前2°过冲约束，而非只追求没有FAULT。

本保存点有Git标签及backups同名源码ZIP；旧v0.15.0（500°/s）、v0.16.0（1000°/s首版）全部保留。数据归档于experiments/gyro1000/trace22_motion_no_fault.csv。当前不需要为保存点重新编译烧录，因为固件没有改变。
