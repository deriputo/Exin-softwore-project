# 瑞士风格上位机界面

版本：`v0.18.0-pc-swiss-ui`。旧界面保留在`v0.17.0-pc-ble-test`及同名ZIP。
用户已确认v0.17.0蓝牙指令可用，之前无回复由接线错误引起；该确认只覆盖已测蓝牙指令，不代表全部功能已验收。

本版修改电脑界面，无需编译/烧录STM32。串口、BLE传输、命令格式、TRACE速率及CSV字段不变。

## 布局

- 米白底、黑灰文字、朱红强调，使用无衬线字体、编号、细分隔线和直角控件。
- 顶部连接区：选择USB/蓝牙、设备、扫描、连接和断开；状态另占一行，避免长蓝牙地址挤掉按钮。
- 左侧分组：时间、闹钟、舵机姿态、设备查询；小窗口可拖左侧滚动条。
- 右侧：目标/实测/误差大字指标、最近10秒曲线、TRACE控制和CSV按钮、原始命令输入、通信日志。
- 蓝牙默认显示配置摘要，“UUID 设置 +”可展开服务/接收/发送字段。展开会占用图表高度；完成配置后收起，可恢复曲线空间。
- 曲线目标为黑色虚线，实测为红色实线，误差为灰色点线；空图提供真实等待提示，不绘制模拟数据。
- 清空曲线或重连会同时清空三项指标，避免旧数据看起来像当前值。仅在接收到TRACE后刷新，不由查询回复推算或填充数值。

## 打开及验收

关闭旧窗口后，PowerShell运行：

```powershell
& 'C:\Users\庄唐旭\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' 'C:\Users\庄唐旭\Documents\ChatGPT\e芯工作室考核实操部分\tools\pc_monitor.py'
```

默认1320×940，最小1100×820（Tk窗口单位，物理尺寸受Windows缩放影响）。小屏可最大化；蓝牙高级配置可收起。

1. 检查连接区、四组控制、图表、命令输入及通信日志均可访问。
2. USB或BLE按原流程连接，点击HELP、IMU ?验证回复；检查时间/闹钟按钮。
3. 点击TRACE ON，检查三项指标与曲线更新、记录CSV；TRACE OFF后停止新的数据输入。
4. 清空曲线后指标恢复“—”，下一帧重新显示。切换连接仍须先断开。
5. 舵机动作不属于本次美化验收；未连接时点击控制应提示连接，不能发送到硬件。

软件验证：10项原有数据/传输回归、3项离线Tk检查（最小BLE布局/锁定切换、15个控制按钮的原指令绑定、指标/日志刷新和清空）。Tk检查使用真实控件但不枚举串口、扫描BLE或连接硬件。另通过computer-use查看实际窗口。不同屏幕缩放和字体仍可由用户反馈微调。
