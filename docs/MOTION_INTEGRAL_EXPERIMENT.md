## 方法及结果

仅在误差偏离目标且角速度超过3°/s时，用growth=-error*rate，Ki_eff=8+(Ki_peak-8)*growth/(growth+scale)。误差进入0.5°死区或开始回位时恢复基础增益。只改变新积分增量，不缩放已有积分，限幅、限速、部分积分抗饱和及故障锁存保持原样。

初轮P0.7、峰值10/12/16/24/32、scale10/30/60/120/240/480共30组；8组通过有限模型过冲门限，但没有同时改善停止后最坏恢复时间。进一步筛选P0.7/1/1.3/1.6/2/2.5、峰值8/10/12/16/24/32及上述scale，共216组，14组通过同一门限，均为P0.7。峰值8等于禁用增强的对照。

单次模型为100ms完成±5/±30°倾斜，执行器时间常数0.01/0.02/0.04/0.08秒、增益1/1.1/1.2、指令延迟0/20ms、测量延迟0/20/40ms，共288组。角度与角速度延迟一致。通过门限为反向过冲不超过2°且进入±1°并保持到20秒结束少于10秒；这只是筛选门限，并非充分的发布条件。

## 下一步：用户采集一次手动阶跃

目的是测量当前安装条件下的指令到姿态响应，不把PWM命令当作真实舵机角度。保持底座固定、IMU牢固随连杆运动，先关闭HOLD，完成静止校准。

1. 上位机连接后点击TRACE ON，开始记录CSV；用“原始命令”发送`SERVO HOLD OFF`及`SERVO SET 90`，等待5秒。
2. 单独发送`SERVO SET 100`，等待5秒，确认连杆及IMU一起转动。
3. 单独发送`SERVO SET 90`，等待5秒，再停止记录。整个过程不要移动底座，也不要用编码器另行调节。
4. 提供CSV，并说明两次是否真实转动。CSV含servo指令和measured姿态，可用于估计可见运动起点、10%～90%响应及姿态稳态变化；50ms记录分辨率、姿态融合延迟和机械延迟无法完全分离，因此不宣称得到纯执行器精确延迟。

这次测试不需要启用HOLD或烧录新固件；保持现有机构不变，便于比较。
