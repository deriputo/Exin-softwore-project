# v0.9.0：DIRECT 受限速度反馈试验

用户已授权增加受限速度反馈，MCU编译与烧录由用户执行；尚未实物验收。

## 算法与参数

20ms控制周期，用上一轮限幅后输出推进执行器位置估计qhat；估计不是实际轴位置反馈。

```text
qhat += dt / (0.12 + dt) * (上一轮输出 - qhat)
e = 目标姿态 - 实测姿态
v += dt / (0.05 + dt) * ((本次姿态 - 上次姿态) / dt - v)
P = 0.30 * e
D = clamp(-0.06 * v, -3°, +3°)
候选输出 = qhat + 方向 * (P + D)
```

方向仍为-1。速度反馈在朝目标运动时帮助制动，背离目标时加强纠偏。它使用实测姿态变化率，不对目标变化求导。±0.5°死区内P/D贡献清零，保持最后输出指令；内部速度滤波继续更新。D的3°上限是控制修正量，不是舵机行程或速度限制。

原0～180°输出范围、180°/s限速、无效/过期样本及时序故障锁存保留。旧PI参数与分支保留，当前没有启用旧Kd。TRACE字段格式不变：P为上述位置项，I为0，D为上述受限速度反馈，servo仍为输出指令。

注意：DIRECT在死区外、未限幅时包含相当于积分的估计状态积累。加快模型并不等于消除了尾调，仍需要实物验证。

## 软件验证

先联合扫描90组无速度反馈参数，未找到满足原过冲标准并明显提速的组合。授权后扫描810组速度反馈候选，144组正向失配模型筛选得到37个通过组合；选择0.30/0.12秒/0.06秒/3°，随后对正反方向完整288组验证。

物理模型时间常数0.06/0.12/0.24/0.40秒、机械增益0.8/1/1.2、指令延迟0/60ms、测量延迟0/60/120ms，扰动±5/±30°。全部保持原过冲门限1.5°，最坏过冲1.29°，最慢进入±1°并保持至仿真结束为2720ms。仿真运行20秒，末段至少保持1秒。

参考模型（物理时间常数0.24秒、增益1、无额外延迟）5/15/30°扰动进入±1°时间为820/1540/1980ms；旧DIRECT为1040/1840/2360ms。改善有限，不能宣称实现实物一步到位。

control_direct、control、app_integration主机测试通过；包括一分钟死区噪声保持、速度贡献限幅、目标变更不产生微分冲击、故障锁存、重复采样、限位和方向检查。尚未Keil编译或烧录。

## 用户测试步骤

1. 用Keil打开Project/eXin.uvprojx，Rebuild并下载。底座水平、连杆90°竖直、IMU牢固固定在连杆上，静置完成校准。
2. 开启HOLD，OLED应显示HOLD Y DIRECT+。查询SERVO HOLD ?确认FAULT=OFF。先完全静置20秒，观察是否来回摆动或抽动。
3. 静止正常再开启TRACE和CSV记录；只做一次约5°底座倾斜，固定支撑后保持15～20秒。记下手完全离开的时刻；过程中不要重新开启HOLD，以免改变目标。
4. 发回CSV及查询回复，说明停止底座后是否还有明显调整、有无过冲。5°通过后再做15°，暂不做80°或端点测试。
5. 若持续摆动，先关闭HOLD；IMU_INVALID仍按原保护处理，不反复开关掩盖故障。
