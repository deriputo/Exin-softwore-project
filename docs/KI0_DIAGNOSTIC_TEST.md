# 关闭积分的静止对照

版本`v0.6.2-ki0-diagnostic`。v0.6.1降低积分后用户仍反馈静止左右摆动；用户同意先禁用积分，保留P/D定位。此诊断版不属于性能优化验收版。

## 改动和验证

固件唯一参数改动：APP_HOLD_NORMAL_KI从0.8改0。Kp1.6、Kd0.02、误差尺度8、死区0.5°、180°/s限速、方向、故障保护均保留。仍是连杆IMU闭环，未改变安装要求。

首次开启HOLD时积分状态清零；Ki为0后不再累积。尺度仍存在但不产生积分作用。不要在运行中的旧固件上仅查看电脑文件就认为已关闭积分，必须重新编译下载。

control/app_integration主机测试通过。应用持续5°输入偏差后，输出与保留的P增益一致，延长10秒没有积分漂移；原非线性积分函数数值测试仍使用非零Ki=0.8，未因当前配置0而变成空检查。保护和限速仍验证。PD模型不能消除持续底座偏差，因此不再要求这个诊断配置通过原完整PI的稳态误差标准，也不报告虚构的60秒恢复时间。

## 用户测试

1. 用户在Keil Rebuild并下载，底座水平且有固定支撑，连杆约90°竖直，IMU随连杆牢固安装。等待静止校准完成。
2. 开启HOLD并确认约90°目标，手离开机构，静置观察20秒。本项不施加倾斜扰动。
3. 反馈左右摆动是消失、减轻还是没有变化。若有条件录制15～20秒TRACE，另存trace_ki0.csv；I列应始终0，P/D及实测角仍会变化。
4. 若仍持续摆动，关闭HOLD；下一项应单独检查Kp、D或测量波动，不能据此继续认定只是积分问题。若不再摆动，说明积分路径参与了此前振荡，但尚不能凭单次试验认定唯一根因。

无故障也不代表完整定角性能合格。暂不用于评估大角度或最终精度，IMU_INVALID仍是未解决问题。助手未执行Keil编译或烧录。
