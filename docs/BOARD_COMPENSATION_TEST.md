# 底座 Pitch 补偿：当前版本测试

历史说明：当前已恢复连杆IMU闭环，该COMP方案不再启用。当前测试见ATTITUDE180_TEST.md。

IMU 和舵机主体都固定在面包板上。该模式按底座角度反向计算补偿，不测量连杆实际角度，不属于考核要求的姿态闭环。最新软件显示 COMP，仍由 KEY2 长按或 SERVO HOLD ON/OFF 开关。方向默认 -1，需要实物确认。

1. 下载新版工程；面包板放平，保持静止完成校准。
2. 发送 SERVO HOLD OFF 和 SERVO SET 90。调整摇臂机械安装，使连杆此时与地面水平；若不能在90°水平，可以手动设定水平位置再开启补偿，程序捕获该位置为起点。
3. 面包板不动，发送 SERVO HOLD ON，进入舵机页应显示 COMP，开启时不会跳转。
4. 绕Y轴缓慢倾斜约10°，先观察动作，切勿直接大幅翻转。IMU ? 的Y增加时，SERVO ? 的输出角度应减少约同样度数。起点90°时，Y约+10°应输出约80°，Y约-10°应约100°，有滤波和死区误差。
5. 面包板回水平，输出回到起始值附近；观察连杆是否也回水平。若补偿导致连杆更加倾斜，先OFF并反馈方向；需要翻转APP_HOLD_DIRECTION，不应靠PID参数修正。
6. 反馈水平/Y正向/Y负向时的Y与OUT，以及静置是否抖动，连杆是否补偿到水平。±90°附近Pitch解算存在奇异，舵机行程仅0～180°；本阶段先测试±10°。

命令全部追加真实换行，电脑115200 8N1。软件无法保证未知摇臂传动比的1:1，若方向正确但残余角度明显，可根据实測调整APP_COMPENSATION_GAIN。故障时发送SERVO HOLD ?检查原因，OFF清除故障后方可重新启用。
