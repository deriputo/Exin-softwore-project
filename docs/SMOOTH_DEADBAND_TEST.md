# 死区边缘平滑接入试验

保存标签v0.14.0-smooth-deadband-test，回退标签v0.13.0-imu-settle-test；Git和backups同名ZIP均独立保留。OLED显示HOLD Y SOFT。

## 目的与证据

用户确认trace19前段持续转动底座，直到末尾才放稳。它不是全程静止试验；不能把31.6～131.6°的前段姿态范围称为机构自行摆动。记录仍能观察到接近目标时的输出回调，例如3.42→3.44秒误差-0.6→-0.2°、P项-0.4→0°、输出130.2→129.7°；25.10→25.12秒误差0.8→0.4°、P项0.6→0°、输出87.7→88.4°。这证明控制指令存在相应修正，不证明全部实物抖动都由此造成。

本轮只平滑PID的误差死区边缘，不再增加P或Ki，不修改IMU。RAW静置快照AX129/AY1022/AZ34mg的模长约1.0307g，确实略超IMU静止快校正的1.03g上界，但计划中的±5%调整因用户反馈小抖动而暂缓，仍保持±3%。不能把本版SOFT标识理解为已放宽IMU条件。

## 算法

ControlConfig.deadband_transition_deg默认0，保留原硬死区。应用设为0.3°，原deadband_deg保持0.5°。PID原始误差仍显示在TRACE的error中；只将P/I计算所用误差平滑处理：

- |e|≤0.5°：e_eff=0；已有积分保持，不清除历史补偿。
- 0.5°<|e|<0.8°：w=(|e|-0.5)/0.3，e_eff=e×w²×(3-2w)。
- |e|≥0.8°：e_eff=e，与旧算法相同。

P=0.7×e_eff，积分新增量按原Ki8与e_eff推进；原积分部分接受、防饱和、0～180°限幅和180°/s限速保持。0.65°误差对应半权重，P约0.2275°；刚越过0.5°时不会立即产生旧约0.35°的P修正。内部使用未四舍五入数值，所以TRACE显示error=0.5时仍可能处于边缘带。

D系数0.005、±0.5°贡献上限和速度输入不变：快速运动中的制动不会因为使用平滑P/I而直接关闭。基于原误差及角速度的D静止抑制也不改。目标设置、故障锁存、过期样本及100ms陀螺仪接续保持。DIRECT/FOLLOW不使用这个参数；默认0的历史PID单元配置不改变行为。

连续函数不能保证离散输出每帧都不变：测量一步跨过整个过渡区、D变化、实际机械死区或供电问题仍可能产生动作。较小误差的修正力度降低，也可能延长精细到位时间，不能宣称抗抖完全免费或已经解决实物问题。

## 软件验证与取舍

23项C主机回归通过，实际应用额外检查0.51°/0.49°及反向小误差脉宽均1500us，避免只改变页面标识而未启用参数。

独立单元输入为：连续1秒每20ms给定0.49/0.51°交替误差，角速度0。旧配置脉宽变化50次，本版0次；这是规定测量输入下的边缘连续性证明，不是闭环实物长期抗抖保证。正反方向、死区内零修正、较大误差与旧输出一致、保留速度制动、非法配置及故障锁存均检查。

7种宽度筛选数据归档于experiments/smooth_deadband/screen.csv；复现python tools/screen_deadband.py，调用真实control.c。不因本轮筛选缩小历史模型范围。

有限模型为100ms完成±5/±30°倾斜，执行器时间常数0.01/0.02/0.04/0.08秒、增益1/1.1/1.2、额外指令延迟0/20ms、角度及角速度共同延迟0/20/40ms，共288组。时间以倾斜开始计，进入误差带后需保持至20秒结束。模型未包含真实IMU融合及所有机械非线性，不能当作整机动态保证。

12组连续往返模型中，RMS最大增加约0.812%；并非提速改善。选择0.3°以减少边缘跳变并限制精细恢复的代价。原宽延迟范围曾未通过2°门限，本版未重新验证该范围，不能以这里的0.7851°宣称所有真实动作过冲都≤2°。

真实IMU核心接活动控制配置、4种假设执行器时间常数、50Hz PWM保持与60秒小重力噪声检查继续通过。该特定人工残差试验最大诱发模型姿态变化0.266°，不代表所有静止场景都无抖动。

## 用户验收

1. 用户在Keil Rebuild并烧录当前Project/eXin.uvprojx。底座水平静置校准，确认HOLD页标题HOLD Y SOFT。编译烧录由用户执行。
2. 进入HOLD，目标保持不变，打开TRACE并记录30～60秒。此次全程固定底座，先看近目标处有无偶发抽动，记录大概发生时刻。提供CSV以及肉眼观察。
3. 静止测试通过后，再另开一份记录：约5°慢速倾斜后支撑固定5秒，回水平再固定5秒。观察是否少了到位后的反向小抽动，以及是否增加明显缓慢尾调；这份动作记录与全静止记录分开。
4. 若持续摆动或故障，停止测试并反馈；安全允许时在关闭HOLD前先采集SERVO HOLD ?、IMU RAW ?和IMU FAULT ?。出现明显超过原2°预算的停止后过冲也应反馈，不继续大角度测试。

本版未操作硬件、未连接串口、未代用户编译或烧录MCU。回退v0.13.0后需重新Rebuild再烧录，不能混用旧编译产物。
