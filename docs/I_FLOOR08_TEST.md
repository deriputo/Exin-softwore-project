# 仅提高积分下限：0.4→0.8

版本`v0.7.1-i-floor08-test`。用户反馈上一版间歇挪动减少、无过冲和持续摆动，但停止转动底座后仍恢复慢；已授权只提高积分下限。

## 改动

唯一固件参数变化：APP_HOLD_INTEGRAL_MIN_KI从0.4改0.8。Kp1.0、Kd0、积分上限1.0、尺度4°、死区0.5°、180°/s限速、20ms周期、方向及故障保护均保留。

```text
Ki_eff = 0.8 + 0.2 * e^2 / (e^2 + 4^2)
候选ΔI = Ki_eff * e * dt
```

小误差附近增益提高：误差1°时约0.812（上一版0.435）；误差8°时0.96（上一版0.88）；误差30°时0.997（上一版0.990）。因此主要加强尾段消差，大误差力度变化较小。死区内仍不积分，已有补偿保留；饱和时仍可能暂停积分。提高积分下限可能重新带来摆动，尚不能宣称已解决实物慢速。

![新版与上一版积分下限对照](nonlinear_integral_curve.png)

更新PNG/SVG/CSV及生成脚本；橙线明确对应v0.7.0的0.4下限，历史曲线可从原标签恢复。

## 软件验证

control及app_integration通过。模型直接使用上一版下限0.4和本版下限0.8比较，其余完全相同，并继续观察到60秒、约束越过目标另一侧过冲不超过1°：

|扰动|下限0.4|下限0.8|
|---|---|---|
|±8°|6280ms|4320ms|
|±30°|9180ms|6920ms|

时间包含进入±1°后1秒保持，不是SG90实测。函数数值、死区、噪声、限速、目标范围、故障锁存和应用积分参与回归继续通过。

## 用户验收

1. 用户Keil Rebuild/下载，底座水平、IMU随连杆固定，等静止校准。助手未编译或烧录MCU。
2. 开HOLD、目标约90°，先静置20秒，看是否重新左右摆动。若持续摆动，关闭HOLD，停止扰动测试。
3. 若正常，TRACE记录新CSV。水平静置约2秒，再用固定支撑倾斜约5°，放好松手后不碰底座，继续记录30秒，不在末尾回正。
4. 小角度正常后再单独录制15～20°，不要在同一文件里反复移动底座而当作单次恢复。记录前后直接查询HOLD状态，不重新开启再证明上一轮状态。
5. 提供CSV，说明放好支撑的时段、最后几度是否更快、有无过冲/持续摆动或间歇挪动。IMU_INVALID时保留首次故障记录，不能把故障停机当稳定。
