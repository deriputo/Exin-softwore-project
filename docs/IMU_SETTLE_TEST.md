# IMU静止尾段收敛试验

版本v0.13.0-imu-settle-test；前一版v0.12.3-response-trace20-test及其ZIP独立保留。OLED的HOLD页面显示HOLD Y SETTLE。

## 问题和证据

用户确认trace16的MANUAL 90→100→90°动作中，第一下动作后实物基本停止。记录1085帧、21.68秒，全部间隔20ms，故障NONE、P/I/D均0；新指令后40ms首次超过最终姿态变化10%，80/100ms超过90%，后续仍约有0.6～0.7°姿态回落。这支持“姿态估计可能参与尾段慢变”，不能证明全部尾调来自融合，也不能把肉眼观察当作真实轴角测量。

90→100°：指令变化后80ms进入末段姿态±1°，300ms进入±0.5°；100→90°分别100ms、520ms。每段末1秒姿态中位数79.6°/89.8°作为最终参考，不是把HOLD目标当手动指令的地面角度。0.2°等边界按CSV一位小数精度处理，不能因浮点表示误差把等于门限判成越界。

## 改动

PID增益、20ms控制周期、0.5°死区、输出限速、20ms电脑TRACE、200ms蓝牙TRACE均不变。只对融合后的单轴tilt_pitch提供有条件的重力校正加速，其他Roll/Pitch显示融合仍0.5秒。

静止证据必须连续满足：

- 已校准、连续可用样本，间隔不超过30ms。
- 三轴去零偏角速度均不超过2°/s。
- 加速度模长位于0.97～1.03g，重力在控制平面的投影平方至少0.25g²。
- 控制轴重力角相对窗口起点变化不超过0.2°，持续至少80ms；超出立即重启窗口。

满足窗口且重力角与预测角之差不超过2°，才把该轴校正时间常数从0.5秒降到0.10秒。加速通道单帧校正量限于6°/s×dt，10ms样本最多0.06°；不是强行把姿态跳到加速度角。若运动、震动、重力不可信、样本间隔增大，立即撤销静止窗口。大于2°的残差继续用原0.5秒校正。

不重设静止零点、不在运行中重校准陀螺仪偏置、不改变重力可信门限、100ms陀螺仪接续、数据过期或故障锁存。静止判据只是传感器上的近似判断；极慢运动或持续外部加速度不一定可与真实静止完全区分。较快重力校正也可能增加噪声影响，因此必须实物验收，不宣称消除了全部HOLD滞后。

新增IMUSample.settling_fast表示该样本实际使用了加速校正；IMU RAW ?末尾SETTLE=1可在静置后观察，SETTLE=0表示该帧未启用。SETTLE=1只表示选择了校正分支，即使误差接近0也可能为1，并非正在转动舵机。RAW的VALID/AGE仍需一并看，诊断不能让无效数据恢复有效。

## 主机验证

- 人工注入0.7°估计残差、真实重力不变且已静止，收敛到0.1°：旧公式990ms，本版270ms。前80ms与旧公式一致，其他姿态显示轴保持旧公式；不是实物提速指标。
- 运动、1.1g、较大姿态残差保留旧校正；静止窗口被间隔、重力角变化及gyro-only打断；校准重置、时间戳回绕、60秒小加速度噪声检查通过。
- 真实IMU核心接当前RATE控制器，加入50Hz PWM保持、4个假设执行器时间常数0.01/0.02/0.04/0.08秒及60秒±0.03°重力角噪声，人工估计残差诱发的最大实物模型变化0.434°，末段输出峰峰值小于0.2°，无故障。此模型只检查估计残差与静止噪声影响，不替代快速底座倾斜试验，未覆盖任意失配与干扰。
- 22项C主机回归通过。原控制器模型数据保持原含义，不能把不包含融合的新模型结果混称为本版整体动态验收。

## 用户验收，一项通过再继续

1. 用户Keil Rebuild并烧录，底座水平、机构和IMU固定不变，保持静止完成校准。确认HOLD页标题为HOLD Y SETTLE；本轮未代用户编译或烧录MCU。
2. 先关闭HOLD，手动90°，打开TRACE和CSV，静置5秒。发送SERVO SET 100，等待5秒；发送SERVO SET 90，再等待5秒，保存CSV。先比较M尾段回落是否缩短，不能只凭感觉判断。
3. 若静止无新增跳变，再开HOLD，目标约90°静置20秒。先做约5°慢速倾斜后固定5秒，再回水平固定5秒；另存CSV，观察尾调、静止抖动及过冲。不立即大幅甩动。
4. 如新增静止抽动、持续摆动、明显超过2°或IMU_INVALID，关闭HOLD反馈。故障前若安全可保留现场发送SERVO HOLD ?、IMU RAW ?、IMU FAULT ?；关闭HOLD会清故障锁存，因此应先采集诊断。回退保存点v0.12.3-response-trace20-test可恢复原融合算法。

本版参数集中在Drivers/IMU/imu_config.h。IMU_SETTLE_ENABLE=0可停用加速通道，但完整回退建议使用Git标签及对应源码ZIP重新Rebuild后烧录，避免混用编译产物。
