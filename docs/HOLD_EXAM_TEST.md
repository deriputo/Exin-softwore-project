# 题目要求的姿态定角：操作与验收

2026-10-14恢复完整PID，APP_HOLD_DIAGNOSTIC=0。控制轴为安装坐标中的Pitch/Y；IMU必须牢固固定在舵机驱动的连杆上。目标是连杆相对地面的姿态：0°水平、90°竖直，目标可设置0～180°。机构需要处于单轴工作平面，安装方向及输出正负关系需实物确认。

## 操作

1. 面包板水平，手动输出90°使连杆竖直，静止完成200次零偏校准。IMU相对Y约0°，HOLD实测姿态M=90°+相对Y。重新校准前关闭HOLD，回手动90°。
2. 进入SERVO页面，长按K2开启HOLD，捕获当前姿态作为初始目标。
3. 转编码器编辑目标姿态，短按K2确认后才生效。HOLD中的目标是对地姿态，不是直接PWM角度。需要退出时长按K2。
4. 每20ms以目标减实测姿态得到误差，PID调整舵机PWM。倾斜底座后，IMU测量连杆实际姿态，控制器推动连杆恢复到设定姿态。

参数P=0.8、I=0.25、D=0.02，死区0.5°；输出500～2500us（0～180°）、速度90°/s，积分贡献限幅并防饱和。取消开启位置±15°限制。数据失效、过期或控制时序异常仍锁存故障并保持最后有效输出；需关闭HOLD后恢复有效数据再重启。

## 分项实物测试

1. **反馈检查**：先关闭HOLD，使用OLED编码器确认手动90→100→90时连杆与IMU真实一起运动，同时记录每点IMU的Y。若输出增加但实测减少，需确认安装坐标/控制方向；若不动、数据不变或异常跳变，先处理驱动或IMU。此前串口动作与用户实物反馈不一致，方向尚未通过验收。
2. **90°静止及扰动**：在参考姿态开启HOLD、确认目标90°，静置10秒，再左右各缓慢倾斜底座约5°，保持倾斜观察连杆是否恢复竖直。若误差不断扩大或输出持续跑向端点，关闭HOLD，记录T/M/OUT及故障，不继续大角度测试。
3. **非零目标**：先测试60°。编码器编辑时目标暂不生效，短按K2后才调整；观察是否稳定到60°，重复小幅底座扰动。
4. **0°目标**：确认机械行程足够后设置0°，观察水平定角，选择机构可达的底座倾斜方向做恢复测试。再测试其他目标角度。机械端点之外的姿态不可达，PID会限幅，不能以无限增大输出强行实现。

软件证据：使用当前应用参数的控制模型测试覆盖0/30/90/120/180目标及底座扰动；实际App/UI集成测试覆盖编码器确认0/180、PWM超出旧诊断范围且保持硬限幅。Keil编译0错误0警告。模型通过不代表实物精度、恢复速度或反馈方向已经验收。
