## 用户测试顺序

1. 面包板水平放稳，IMU随连杆固定。下载后舵机回90°并重新静止校准；等待IMU校准完成。进入舵机页，长按KEY2开启HOLD，捕获约90°的对地姿态。
2. 静止观察10秒。连杆应基本稳定，无持续左右摆动，无IMU_INVALID。
3. 将面包板沿控制轴在约半秒内倾斜5°，保持底座不动。观察连杆是否很快开始反向补偿，再观察恢复到原对地姿态需要多少秒、是否来回摆动。
4. 回到水平后，以相反方向重复5°。先验收这两次小幅扰动，不直接试机械端点或大角度。
5. 反馈：静止是否抖动，动作开始是否仍明显延迟，稳定大约耗时几秒，是否过冲或振荡，OLED有无fault。若持续摆动或再次故障，长按KEY2关闭HOLD，或单独发送`SERVO HOLD OFF`。

需要遥测时由串口助手发送`SERVO TRACE ON`，采集后单独发送`SERVO TRACE OFF`；命令末尾使用实际CRLF。通过`SERVO HOLD ?`查看target、measured及FAULT。测试当前模式始终为IMU装在被控连杆上的PID闭环。
