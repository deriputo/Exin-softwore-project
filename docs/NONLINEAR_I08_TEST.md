# 保留Kp、减弱变速积分

标签`v0.6.1-nonlinear-i08-test`。用户反馈v0.6.0静止时左右抽动，关闭HOLD后查询OFF/FAULT=OFF，目标92.9、实测93.4；不能凭关闭后的快照确定P/I谁主导振荡。用户不采用整体回退，明确要求保留Kp，减少小误差附近的Ki。

## 唯一控制参数改动

APP_HOLD_NORMAL_KI从2.0降至0.8。保留Kp1.6、误差尺度8°、Kd0.02、死区0.5°、限速180°/s、方向-1、位置式PID、积分抗饱和及IMU故障保护。

```text
Ki_eff = 0.8 / [1 + (e / 8)^2]
候选ΔI = Ki_eff * e * dt
```

由于是减小增益峰值，所有误差下增益和候选增量均为失败版的40%，并非只对小误差局部修改。小误差接近死区时增益约0.8，|e|<=0.5°仍停止累积；已有积分保留。

|误差绝对值|Ki_eff|候选积分增量绝对值/20ms|
|---|---|---|
|1°|0.788|0.0158°|
|5°|0.575|0.0575°|
|8°|0.400|0.0640°|
|16°|0.160|0.0512°|

## 验证与用户测试

control及app_integration通过。相同8°简化模型含1秒达标保持：恒定Ki0.5/Kp0.8为6420ms；新参数为4920ms；失败版为2600ms。模型更快没有保证实物稳定，本次有意减弱积分，不继续追求最短模型时间。

1. 用户Keil Rebuild并烧录，底座水平、IMU随连杆固定，等待校准。助手未烧录。
2. 开HOLD，目标约90°，先静置15秒，不施加扰动。观察是否仍左右抽动；先验收静止表现。
3. 若静止正常，再用固定小支撑倾斜约5°，松手后不再碰底座，录制30秒TRACE到新的CSV。
4. 若静止仍持续左右抽动，关闭HOLD并反馈，暂不做扰动测试。此时不能断言只是积分问题，应单独核对Kp或姿态测量噪声。
