# HOLD反馈方向诊断（2026-10-14）

**此文件为历史诊断版记录。用户要求恢复题目功能后，已关闭APP_HOLD_DIAGNOSTIC，恢复完整PID与全输出范围。当前测试以[题目模式验收](HOLD_EXAM_TEST.md)和进度记录为准。**

当前应用启用临时 `APP_HOLD_DIAGNOSTIC=1`：Kp=0.5、Ki=0、Kd=0；HOLD输出限制在开启时舵机位置±15°，并保留0～180°硬限幅和90°/s限速。从手动90°开启时，HOLD输出只能在75～105°之间。OLED显示 `HOLD Y TEST`。手动模式仍可设置0～180°。

这是用于查反馈的临时版本，不作为全范围定角验收版本。关闭积分后存在静态误差，不能用恢复精度评判最终性能。反馈方向确认后再关闭诊断开关、恢复正常PID并逐项验收。

## 第一步：手动反馈

1. 关闭HOLD，底座水平，IMU固定在随舵机运动的连杆上；手动90°应对应连杆竖直。下载后保持静止约3秒，等待校准完成。
2. 串口助手单独发送 `IMU RAW ?`，必须确认VALID=1、CAL=1、COUNT=200；否则先处理IMU故障。
3. 手动设置90°，稳定约1秒后查询 `IMU ?` 并记下Y；设置100°，实物稳定后再查询；最后回90°重复查询。每条命令使用实际CRLF结束。
4. 同时观察连杆与IMU是否一起转动。若100°对应Y增加约10°，支持当前正向反馈；若减少约10°，需要调整反馈方向；若Y几乎不变或突然跳变，先查控制轴、安装或数据可靠性，不能盲目反转方向。

## 第二步：小幅HOLD

只有第一步确认反馈可靠后才执行。从手动90°开启HOLD，捕获当前约90°目标，不修改成其他大角度。先静置10秒，再将底座沿控制轴缓慢倾斜约5°。记录 `SERVO HOLD ?`、`SERVO ?`，必要时开启短时TRACE。输出应向减小姿态误差的方向改变；此诊断版可能保留误差。若误差扩大、输出停在75/105°边界或出现IMU_INVALID，关闭HOLD并保存数据。
