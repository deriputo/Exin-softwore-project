# 当前0～180°考核闭环版本

IMU必须固定在舵机带动的连杆上。用户实测：输出90°时连杆竖直且相对Y≈0；100°时Y≈+9.1；80°时Y≈-10.7。选择Pitch/Y，PID正向。M=90+相对校准Y，因此90表示竖直、0/180表示两侧水平。

每次校准须底座水平、输出90°且连杆竖直。上电自动校准；手动重校准先HOLD OFF、SERVO SET 90、稳定后在IMU页长按K2。重新校准时底座倾斜或连杆不竖直会使参考错位。IMU ?和IMU页Y仍为相对校准角，HOLD ?和舵机页M是对地角。

第一轮只测试80/90/100，暂不测试端点：

1. 开启HOLD，屏幕显示HOLD Y，T/M应约90。
2. 编码器设置T=100并确认，等待稳定，M应接近100；再设80，最后回90。
3. 目标90时缓慢倾斜底座约±5～10度，观察连杆保持竖直的方向和恢复。若越调越偏或出现FAULT，立即OFF并记录TRACE，不盲目反转方向。
4. 反馈目标、稳态M、OUT、摆动幅度和恢复时间。参数尚需真实机构调试。

第一轮通过后再逐步扩大目标范围30/60/120/150，最后确认0/180端点无卡滞。0～180是目标姿态设置范围，不保证底座任意姿态下都有足够机械行程可达。饱和时有安全限幅，不能继续强求补偿。

AutoDebug自动采样只能验证真实UART数据及静止观测；不能替代外部量角和人工底座扰动。脚本通过条件与实际报告保存在build/autodebug_serial，不使用无条件固件通过令牌。
