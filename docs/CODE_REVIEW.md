## 阅读时需要了解的行为与限制

- 普通复位会按赛题初始化 RTC 时间为 23:59:55，三个闹钟默认关闭。当前只在可选真正 Standby 的恢复路径保留状态，不是普通掉电持久化时钟方案。
- 30 秒无操作后的默认行为为普通 Sleep 并关闭 OLED。TIM2 每 5 ms 唤醒，IMU、RTC、PWM 和串口继续处理，因此不能把该策略当作深度低功耗模式。
- MPU6050 需要静止校准；Yaw 是相对积分值，有漂移。闭环默认使用 Roll。
- PID 的安装轴、控制方向和参数仍需实物调试，软件仿真通过不等于实际机械系统已经稳定。
- 舵机 500～2500 us 按用户给出的占空比范围实现，具体舵机的机械可用范围须实测。
- 未实测 PWM 波形、RTC 精度、长时间运行栈高水位和睡眠电流，也未完成真实串口全功能验收。自查通过不构成“没有任何问题”的保证。
